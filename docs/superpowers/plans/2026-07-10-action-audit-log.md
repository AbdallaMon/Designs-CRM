# Action Audit Log Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A rich, semantic, admin-only action audit trail written from usecases, with a paginated filterable viewer for ADMIN/SUPER_ADMIN.

**Architecture:** New additive `ActionAuditLog` table; a non-blocking `recordAction` infra service usecases call after successful writes; a standard six-file `/v2/audit-logs` read module; an admin-only config-driven frontend feature; permission `audit.log.view` granted to ADMIN/SUPER_ADMIN only.

**Tech Stack:** Node/Express 4, Prisma 6 (MySQL), Zod 4, `@dms/shared`, Next 16 App Router, MUI v7, react-hook-form, `useRequest`/`getData` data layer, Vitest.

## Global Constraints

- Layering is strict: `route → controller → usecase → repo → validation → dto`. Prisma ONLY in `*.repo.js`. No business logic in routes/controllers.
- File suffixes: `*.route.js`, `*.repo.js` (NOT `.routes.js`/`.repository.js`).
- API envelope everywhere: `{ success, message, data, translationKey }`. `message` is a language-neutral CODE, never prose. Errors use `AppError`.
- Paginated lists return `data: { items, total, page, pageSize }`.
- `@dms/shared` is framework-agnostic: NO Prisma/Express/Next/React imports.
- Authorization = auth + permission code (never role-alone, never wildcards). Audit viewer is ADMIN/SUPER_ADMIN only.
- Never change the Prisma schema by hand in MySQL; the schema edit is authored, the USER runs `prisma migrate dev`. Never touch prod.
- JS only in source (no TypeScript). ESM (`import`).
- Verify FE with `cd web && npx next build` (eslint config is broken). Verify BE with `npm test`.
- Audit writes must NEVER break the business operation (swallow errors) and NEVER log secrets (redact deny-list).

### Task 3: Diff/redact helper (`diff-fields.js`)

**Files:**
- Create: `server/src/infra/audit/diff-fields.js`
- Test: `server/src/infra/audit/__tests__/diff-fields.test.js`

**Interfaces:**
- Produces: `diffFields(before, after, allowedKeys?) → { changed: string[], before: {}, after: {} }` with sensitive keys redacted to `"[redacted]"`.

- [ ] **Step 1: Failing test** — changed keys only; unchanged keys omitted; `password`/`token`/`arToken`/`enToken`/`chatAccessToken`/`sessionString`/`apiHash` redacted; `allowedKeys` restricts scope; null/undefined before ⇒ all after keys "added".
- [ ] **Step 2:** Run → FAIL.
- [ ] **Step 3:** Implement:

```js
const REDACT = new Set(["password","passwordHash","token","arToken","enToken","chatAccessToken","sessionString","apiHash","refreshToken","accessToken","access_token","refresh_token"]);
const redact = (k, v) => (REDACT.has(k) ? "[redacted]" : v);
export function diffFields(before = {}, after = {}, allowedKeys) {
  const b = before || {}, a = after || {};
  const keys = allowedKeys?.length ? allowedKeys : [...new Set([...Object.keys(b), ...Object.keys(a)])];
  const changed = [], outB = {}, outA = {};
  for (const k of keys) {
    if (JSON.stringify(b[k]) === JSON.stringify(a[k])) continue;
    changed.push(k); outB[k] = redact(k, b[k]); outA[k] = redact(k, a[k]);
  }
  return { changed, before: outB, after: outA };
}
```

- [ ] **Step 4:** Run → PASS. Commit.

### Task 4: Audit repo + `recordAction` service (non-blocking)

- Produces:
  - `actionAuditRepository.create(row) → Promise<void>`; `actionAuditRepository.findManyPaged(filter) → { items, total }`.
  - `recordAction(ctx, event) → Promise<void>` where `ctx = { actorUserId, actorRole, ip }`, `event = { module, action, entityType?, entityId?, clientLeadId?, summary?, before?, after?, detail?, allowedKeys? }`. NEVER throws.

- [ ] **Step 1: Failing test** for `recordAction`: builds a row with the computed diff into `detail`; calls repo.create; when repo.create rejects, `recordAction` resolves (swallow) and does not throw.
- [ ] **Step 2:** Run → FAIL.
- [ ] **Step 3:** Implement `action-audit.repo.js` (Prisma-only): `create({ ... }) => prisma.actionAuditLog.create({ data })`; `findManyPaged({ where, skip, take }) => prisma.$transaction([findMany(orderBy createdAt desc), count])` returning `{ items, total }`.
- [ ] **Step 4:** Implement `record-action.js`:

```js
import { diffFields } from "./diff-fields.js";
import { actionAuditRepository } from "./action-audit.repo.js";
export async function recordAction(ctx = {}, event = {}) {
  try {
    const { before, after, allowedKeys, detail, ...rest } = event;
    const diff = before || after ? diffFields(before, after, allowedKeys) : null;
    await actionAuditRepository.create({
      actorUserId: ctx.actorUserId ?? null,
      actorRole: ctx.actorRole ?? null,
      ip: ctx.ip ?? null,
      module: rest.module, action: rest.action,
      entityType: rest.entityType ?? null, entityId: rest.entityId ?? null,
      clientLeadId: rest.clientLeadId ?? null, summary: rest.summary ?? null,
      detail: detail ?? diff ?? null,
    });
  } catch (e) { console.error("[audit] recordAction failed:", e?.message); }
}
export function auditCtxFromReq(req) {
  return { actorUserId: req?.auth?.id ?? null, actorRole: req?.auth?.role ?? null, ip: req?.ip ?? null };
}
```
